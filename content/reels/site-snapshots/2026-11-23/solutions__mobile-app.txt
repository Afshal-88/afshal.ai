01
Shape the idea
Cut the idea down to the smallest app people would actually use.
App idea to MVP
Any AI
Copy prompt
My app idea: [IDEA]. Users: [WHO]. Problem it solves: [PROBLEM].
1. Ask me 5 questions to sharpen the idea.
2. Then define the first version (MVP): the one main job, max 5 features, and what to leave out for later.
3. List 3 similar apps and what my app must do better.
4. Name the riskiest assumption and a cheap way to test it this week.
02
Map the screens
Every screen and how users move between them, before any design.
Screens and flow
Same chat
Copy prompt
For the MVP above, list every screen. For each: its name, what the user sees, what they can do, and where each button goes. Then write the main user journey from first open to the "aha" moment in 6–8 steps. Mark which screens need login and which data each screen reads or saves.
03
Design the screens
A design system and screen-by-screen descriptions you can build or mock up.
App design
Same chat, or a design AI
Copy prompt
Create a simple design system for my app: colours (hex), font, spacing scale, button styles, input style, card style, icons set. Then describe each screen from the list above in detail (layout top to bottom, components, empty state, loading state, error state). Keep it clean, thumb-friendly and readable at 360px width.
